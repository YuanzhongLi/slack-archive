# プロジェクト概要

## ビジョン
Slack無料プランの90日制限を超えて、チームの会話履歴を永続的に保存・閲覧できる自前アーカイブシステム。

## 背景と動機
Slack無料プランは90日を超えるメッセージ履歴が失われる制約がある。有料プランへの移行コストをかけずに、Slack APIを使って定期的にデータを同期・保存することで、チーム独自のアーカイブを構築する。

## 解決する課題
- 90日以上前のメッセージが参照できない
- 過去の意思決定・技術的議論が失われる
- 有料プランへの移行コストが高い

## ターゲットユーザー
Slack無料プランを使用しているチームのメンバー。過去の会話を検索・閲覧したい開発者・運営者。

## スコープ

### 今回やること
- Slack APIを使ったメッセージ・ユーザー・チャンネル情報の取得と同期
- Cloudflare D1へのデータ永続化
- Slackライクな UIでのメッセージ閲覧（チャンネル一覧・メッセージ履歴・スレッド）
- Google認証（CF Access）+ Worker側DB認可によるアクセス制御
- `/management` ページでの手動同期・自動同期設定
- Cloudflare Cron Triggersを使った定期自動同期

### 今回やらないこと
- ファイル添付のアーカイブ（R2連携が必要、Phase 2以降）
- リアクション（絵文字）のアーカイブ（Phase 2以降）
- DM・プライベートチャンネルのアーカイブ（権限スコープが異なるため要検討）
- マルチワークスペース対応（1プロジェクト = 1ワークスペースとしてclone運用）
- リアルタイム同期（WebSocket/Event API）
