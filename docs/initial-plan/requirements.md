# 要件定義

## 機能要件

### Must（必須）

- [ ] パブリックチャンネル一覧の取得・保存
- [ ] チャンネルメッセージ履歴の取得・保存
- [ ] スレッド（replies）の取得・保存
- [ ] ユーザー情報（表示名・アイコンURL）の取得・保存
- [ ] Google認証（CF Access）によるログイン
- [ ] Worker側DBによる認可（`users`テーブルのrole確認）
- [ ] Slackライクなチャンネル一覧 + メッセージ表示UI
- [ ] `/management` ページでの手動同期実行
- [ ] Cloudflare Cron Triggersによる自動同期
- [ ] `/management` ページでの自動同期スケジュール設定

### Should（重要）

- [ ] メッセージ検索
- [ ] 差分同期（前回同期以降の新着のみ取得）
- [ ] 同期ログ・履歴の表示
- [ ] ユーザー管理（`users`テーブルへの追加・削除）

### Could（あると嬉しい）

- [ ] リアクション（絵文字）のアーカイブ
- [ ] DM・プライベートチャンネルのアーカイブ
- [ ] メッセージのピン留め表示

### Won't（今回はやらない）

- ファイル添付のアーカイブ: R2連携が必要なため Phase 2 以降
- マルチワークスペース対応: 1プロジェクト = 1ワークスペースのclone運用で代替
- リアルタイム同期: Slack Event APIのWebhook設定が必要で複雑度が高い

## 非機能要件

- **認証**: Googleアカウントを持つユーザーのみ CF Access を通過できる（bot対策・2FA活用）
- **認可**: `users`テーブルに登録されたemailのみアクセス可能
- **データ保持**: D1（最大5GB）に全メッセージを永続保存
- **同期頻度**: Cron Triggersで最短1時間ごと（無料枠内）
- **Slack APIレート制限**: Tier 3（50+ RPM）を考慮した実装
- **Node.js**: v24を使用
